# IdiomLens – демо

Демонстраційна веб-сторінка ПП IdiomLens: AR-застосунок для вивчення складних англійських ідіом за навчальними Flash-картками з AR-маркерами.

Наведіть камеру смартфона на картку – сторінка розпізнає AR-маркер, покаже назву і значення ідіоми, відтворить її вимову та відкриє відеоуривок з прикладом вживання в реальному контексті.

## Як спробувати

1. Роздрукуйте картки з файлу `cards/print-a4.pdf` або відкрийте зображення карток з папки `cards/` на екрані іншого пристрою.
2. Відкрийте сторінку на смартфоні в Safari (iOS) або Chrome (Android).
3. Натисніть «Сканувати» і дозвольте доступ до камери.
4. Наведіть рамку на картку на відстані 15–40 см.

## Структура

| Файл | Призначення |
|---|---|
| `index.html` | сторінка: екрани «Відсканувати картку», «Ідіома», «Приклад у контексті» |
| `targets.mind` | скомпільовані зображення AR-маркерів трьох карток для MindAR.js |
| `cards/*.png` | зображення карток break the ice, spill the beans, hit the books |
| `cards/print-a4.pdf` | аркуш A4 з трьома картками для друку |

## Технології

- [MindAR.js](https://github.com/hiukim/mind-ar-js) 1.2.5 – розпізнавання AR-маркера зображення в браузері;
- three.js 0.160 – AR-шар поверх зображення з камери;
- Web Speech API – вимова ідіоми;
- YouTube embed – відеоуривок з прикладом вживання (зовнішній сервіс медіаконтенту).

Камера в браузері доступна лише через HTTPS, тому сторінку розміщено на GitHub Pages.

## Обмеження демо

- дані трьох ідіом вбудовано в сторінку, без серверної частини на Laravel і БД MySQL;
- вимову озвучує синтезатор мовлення браузера, а не MP3-запис диктора.
